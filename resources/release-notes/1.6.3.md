# 1.6.3

silo 1.6.3 gives the admin silo's own logo, and builds the executables and the
Docker image with Bun 1.4.4.

## New: the silo logo

- **The admin shows the silo logo** in the sidebar and in the Server Browser.
  It follows the light and dark themes.
- **The browser tab shows the logo.** The favicon is dark on a light tab bar
  and white on a dark one. Browsers that cannot show an SVG favicon get the
  logo on a dark tile.
- **An iPhone or iPad shows the logo** when you add the admin to its home
  screen.
- **The docs site uses the logo** in its navigation bar and as its favicon.

## Changed: built with Bun 1.4.4

- The release executables and the Docker image (`oven/bun:1.4.4-alpine`) now
  use Bun 1.4.4 instead of 1.4.2.
- **A Postgres certificate for the wrong host still gets a clear message.**
  With `sslmode=verify-full`, Bun 1.4.4 reports a certificate that does not
  name the host differently from Bun 1.4.2. silo reads both, and still says
  that the certificate "does not name the host [storage] url connects to".

## Version

- Package versions are 1.6.3 in the root, `apps/admin`, `apps/server`,
  `packages/create-silo-plugin` and `packages/shared`.
