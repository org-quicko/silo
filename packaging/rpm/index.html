silo — dnf repository

Packages for Amazon Linux 2023, RHEL 8/9 and derivatives, and Fedora, on x86_64 and aarch64.

Install

sudo curl -fsSL -o /etc/yum.repos.d/silo.repo https://org-quicko.github.io/silo/silo.repo
sudo dnf install silo

The package installs a silo system user, a config file at /etc/silo/silo.toml, a data directory at /var/lib/silo, and a systemd unit. Nothing starts on install: 

sudo systemctl enable --now silo

On first start silo prints a root API key to the journal, once and never again: 

sudo journalctl -u silo | grep -A2 'root API key'

Verification

Packages and the repository index are both signed with silo's release key, and the repo file turns on gpgcheck and repo_gpgcheck, so dnf checks both for you. To inspect the key yourself: 

curl -fsSL https://org-quicko.github.io/silo/SIGNING_KEY.asc | gpg --show-keys
