# silo — instructions for AI assistants

- Read [CONTEXT.md](CONTEXT.md) first — it describes the current state of the
  project. [IMPLEMENTATION.md](IMPLEMENTATION.md) is the design spec; check its
  decisions log (D1–…) before proposing architectural changes.
- Any change to code, architecture, or repo layout MUST update CONTEXT.md in
  the same change set.
- NEVER run `git add`, `git commit`, or `git push` in this repo. The user
  stages and commits everything themselves. Leave the working tree dirty.
